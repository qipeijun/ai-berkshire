## 4. 第二步：生意本质分析 —— 段永平"对的生意"

### 4.1 一句话定义

**微软是一门"向全球知识工作者与企业收基础设施税"的生意：你不用它的产品，你的员工就无法协作、你的开发者就无法部署、你的数据就无法运行——它卖的不是软件，是"不采用的代价"。**

### 4.2 段永平式追问：这门生意好在哪？

用一句话：**"客户一旦进来就出不去，而出去的替代方案永远比它贵、比它慢、比它碎。"**

拆成三个可验证的机制：

| 机制 | 事实支撑 | 强度 |
|------|---------|:----:|
| **订阅化 + 复购刚性** | FY26 递延收入 75,712（未来 12 月确认 72,965）；Microsoft Cloud 全年 $214.4B；商业 RPO $678B（+84%），加权剩余期限 2.3 年 | 极强 |
| **提价权已被验证** | 2026-07-01 起 E3 $36→$39、E5 $57→$60（+8%）；新增 E7 Frontier Suite **$99/用户/月**；Copilot $30/用户/月另计 | 强 |
| **经营杠杆持续释放** | 经营利润率 42.05%（FY22）→ 46.78%（FY26），4 年 +4.7pp，且在收入翻倍基础上实现 | 强 |

**但必须同时看到生意的另一面**（本报告与"微软无敌"叙事的分歧点）：

| 反面事实 | 数据 | 含义 |
|---------|------|------|
| 席位增长已经很慢 | M365 商业席位 FY26 仅 **+6%** | 增长越来越依赖**提价**而非**新增客户** |
| 新引擎是资本密集型 | CapEx 占收入 **34.9%**、占经营现金流 **63.4%** | 从"轻资产印钞机"变成"重资产基建商" |
| FCF 已经不增长 | FY22 65,149 → FY26 66,987，**4 年 0.7% CAGR** | 段永平最看重的"真实到手的钱"停滞了 |
| 有一块在萎缩 | MPC 分部 −1.1%；Xbox 内容与服务 FY26 全年 −5%、Q4 −10%，含减值与遣散 | 不是全线好生意 |

### 4.3 商业模式画布

| 维度 | 微软 | 判定 |
|------|------|:----:|
| 收入性质 | **订阅/复购为主**（M365、Azure consumption、LinkedIn Premium、Game Pass），一次性销售（Windows OEM、Xbox 硬件）占比下降 | 优 |
| 硬件/软件/平台 | 软件 + 平台 + 基础设施三层叠加；硬件（Surface/Xbox）是生态入口非利润中心 | 优 |
| 客户锁定 | 企业级 ID（Entra）+ 数据（Fabric/Synapse）+ 应用（M365）+ 基础设施（Azure）四层绑定；迁移需同时动四层 | 极优 |
| 毛利率 | 67.94%（FY26，同比 −0.88pp），Microsoft Cloud 毛利率 65%（Q4，同比下滑） | 优但在**缓慢恶化** |
| 经营杠杆 | 4 年利润率 +4.7pp；但 capex 折旧开始反向侵蚀（FY27 起折旧年限 15→25 年，部分缓解） | 中性偏正 |

### 4.4 生意质量评分：**8.5 / 10**

扣分项：(1) 增长引擎从软件切换到数据中心，资本强度上升一个数量级；(2) AI 应用层的 per-seat 模式正被 AI 原生工具侵蚀（66% 的 Copilot 客户同时用 ≥2 个 AI 助手）；(3) 游戏业务进入收缩周期。

> **段永平式追问的回答**：如果明天股市关闭 5 年，这门生意本身**愿意持有**——它仍是全球最强的企业分发网络之一。问题不在生意，在价格（见第 9 节）。

## 5. 第三步：护城河评估 —— 巴菲特"经济护城河"

### 五类护城河逐一验证

| 护城河类型 | 验证问题 | 证据 | 强度 | 5年趋势 |
|-----------|---------|------|:----:|:-------:|
| **转换成本** | 客户迁移到竞品的成本？ | 4.6 亿 M365 商业席位；ID/数据/应用/基础设施四层绑定；75% Fortune 500 用 Azure；NHS 50.5 万席、Accenture 74 万席巨额合同 | **9.5/10** | → 持平（Copilot 是新增锁定层，但多 AI 助手并存削弱单一锁定） |
| **网络效应** | 用户越多产品越好吗？ | GitHub 2.25 亿用户 / 1.8 亿注册开发者；LinkedIn **12 亿+** 会员（连续 5 年双位数会员增长）；Agent 365 上线 2 个月 4,000 万已注册 agent | **8/10** | ↑ 变宽 |
| **规模效应** | 规模带来的成本优势？ | FY26 新增 88 座数据中心、两年容量约翻倍；GPU 上架到通电时间缩短近 50%；自研 Maia 200（性能/美元 +30%）、Cobalt CPU | **8.5/10** | ↑ 变宽（Google/AWS 同样规模化，优势是相对的） |
| **品牌/定价权** | 能否不损失销量提价？ | 2026-07 E3/E5 提价 8% 席位未见流失；E7 定价 $99/月；Copilot $30/月渗透 6.5% 却已 3,000 万席 | **8/10** | ↑ 变宽 |
| **技术/专利壁垒** | 技术领先几年？ | ⚠ **最弱一环**：核心 AI 模型来自 OpenAI（非独占）；Anthropic 企业 LLM 份额 40% 居首、编码 54%；自研 MAI/Maia 起步晚 | **6/10** | ↓ 变窄 |

### 护城河综合评分：**8.0 / 10**

**关键判断：微软的护城河是"分发型"而非"技术型"。**

它最深的护城河是"**你已经在用我**"，而不是"**我的技术你做不出来**"。这个区别在 AI 时代变得重要：
- 分发型护城河在**企业软件层**几乎不可摧毁（转换成本 9.5/10）；
- 但**模型层和 AI 应用层**的护城河明显更窄——Anthropic 在企业 LLM 支出上已拿 40% 份额，Claude Code 年化 $2.5B，Cursor 被 SpaceX 以 $60B 收购。

> **巴菲特式追问：10 年后这条护城河还在吗？**
>
> **企业分发层（M365/Entra/Azure 基础设施）：大概率还在，且可能更宽**——AI 让企业更需要统一的身份、数据与合规层。
>
> **能摧毁它的东西有三样**：
> 1. **模型中立化**——当 Anthropic/OpenAI/开源模型都能通过 AWS Bedrock 或 GCP 交付，Azure 的"模型独家"溢价消失（2026-04-27 起 IP 授权已改为非独家）；
> 2. **AI 原生工作方式替代 per-seat**——如果员工不再打开 Word/Excel 而是直接对 agent 说话，M365 的席位价值被架空；
> 3. **监管强制互操作**——英国 CMA、欧盟 DMA 一旦强制拆捆绑，转换成本被制度性削减。
>
> 这三样不是"会不会发生"，而是"正在发生多少"。

**芒格会指出的最重要分叉是思科 vs AWS**：
- 思科的客户是"建设互联网的电信商"——一次性、周期性、可延迟；
- 微软的客户是"经营业务的企业"——持续性、订阅性、不可延迟。

**这个区别是微软更像 AWS 而非思科的核心理由**，也是本报告对基本面判断偏正面的结构性依据。

## 8. 第六步：行业与文明趋势 —— 李录"文明演进框架"

### 8.1 这是文明级范式转移吗？

**是。** 判断依据（不是口号，是可验证的支出数据）：

| 指标 | 数据 | 来源 |
|------|------|------|

**历史类比**：当前 AI 更接近 **1996–1999 的互联网**（基础设施先行、资本开支爆发、真实需求与泡沫并存），而非 2010–2015 的移动互联网（应用层清晰、资本开支温和）。

**这个类比对微软的含义是双向的**：
- 互联网历史告诉我们：**基础设施供应商是第一轮赢家**（思科/Oracle/Microsoft 在 1990s 都是最大受益者）；
- 但也告诉我们：**第一轮赢家不一定吃到第二轮**（思科没能吃到应用层）。

### 8.2 微软在产业价值链中的位置

```
[芯片] NVIDIA / AMD / 自研 Maia
   ↓
[云基础设施] AWS 28% ★ / Azure 20% ★ / Google 15% ★   ← 微软在这里
   ↓
[模型层] Anthropic 40% / OpenAI 27% / Google 21%       ← 持股 OpenAI 27% 但非独占
   ↓
[编排/平台层] Bedrock / Vertex / Azure AI Foundry ★      ← 微软在这里（10 万客户）
   ↓
[应用层] M365 Copilot ★ / GitHub Copilot ★ / Dynamics ★  ← 微软在这里（最大分发口）
   ↓
[最终用户] 4.6 亿企业席位 ★ / 12 亿 LinkedIn ★ / GitHub 1.8 亿开发者 ★
```

**关键洞察**：微软是**唯一在价值链 4 层都有布局的玩家**（AWS 缺应用层、Google 缺企业分发、Anthropic/OpenAI 缺分发）。这是它最大的结构性优势——**它不需要在任何一层赢，只需要在每一层不输**。

> - **不是 3Com**：3Com 的护城河是单一技术标准，被以太网迭代即死；微软的护城河是**企业组织的行为惯性**（ID、数据、流程、合规），技术迭代不会自动瓦解它。
> - **不是标准石油**：标准石油靠物理管网垄断（天然垄断、监管拆分）；微软的云是可替代的（AWS/Google 同场竞争），份额稳定在 20% 说明它**没有垄断定价权**。
> - **像电力公司**：需求确定、长期增长、资本密集、受监管、回报率受资本开支压制。这正是它 2026 年的估值困境——**电力公司的增长故事，被给了一个成长股的估值**。
>
> 20 年后大概率还在，且大概率仍是有意义的赢家；但**大概率不是那 20 年里回报最高的那只股票**——回报最高的会是模型层或应用层某个今天还没被充分定价的玩家。
